3D castles built by coding agents

Read the blog post 3D castles with Claude, Codex, DeepSeek and Mistral

Each sample started from the same single prompt, using Claude Code, Codex, DeepSeek Harness or Mistral Vibe:

Create a 3d animation that runs completely in browser. The animation features a medieval castle, sitting on top of a hill that is located on large forest. Do not add any keyboard controls, just make the camera spin around the castle so that we see it from all sides. On top of the castle tower there should be a flag that waves in the wind. The output should contain index.html file that when executed shows the castle and starts the looping animation.

The models were able to use browser to check the results and adjust code. Unless otherwise noted, the code here is what the model came up with. I did not give human feedback for the model/harness.

The GPT-5.6-Luna had small issue that prevented it from running straight from Codex, that has been fixed. Astra was also used to tweak the animations a bit so that I was able to create the looping video.
