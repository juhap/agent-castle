# The Verdant Keep

Open `index.html` directly in a modern browser with WebGL enabled. The animation starts automatically; no server, installation, internet connection, or controls are needed.

The self-contained scene includes a medieval castle on a forested hill, a continuously orbiting camera, an animated fabric flag, soft shadows, distant mountains, clouds, and gliding birds. It adapts to desktop and mobile screens.

Three.js r128 is embedded in the HTML, together with its MIT license.

Verified in Chromium: rendering without JavaScript errors, camera motion, flag deformation, desktop/mobile layouts, and the opposite side of the castle.
